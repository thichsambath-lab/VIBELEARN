# Implementation Prompt: Phase 5 - Deployment

## 1. Goal
Prepare and configure production deployments for the entire Vibelearn platform: configure Vercel for the React frontend (SPA routing, build settings), configure Render for the Node.js/Express backend (web service, health check, environment variables), verify production builds and linting across both workspaces, and provide complete documentation and verification for production readiness.

## 3. Code & Environment Inspected
- `frontend/`:
  - Framework: Vite + React (SPA using `react-router-dom`).
  - Build script: `vite build` targeting `dist/`.
  - Env variables: `VITE_CLERK_PUBLISHABLE_KEY`, `VITE_API_URL` (or `VITE_API_BASE_URL`).
  - Requires `vercel.json` to handle client-side routing on page refresh.
- `backend/`:
  - Runtime: Node.js (ES Modules), Express.
  - Start script: `node src/index.js`.
  - Health check endpoint: `GET /api/health`.
  - Database: Drizzle ORM connecting to Supabase PostgreSQL via `DATABASE_URL`.
  - Auth: Clerk Express middleware using `CLERK_SECRET_KEY` and `CLERK_PUBLISHABLE_KEY`.
  - Requires `render.yaml` web service specification.

## 4. Decisions and Assumptions
- **Frontend Configuration (`frontend/vercel.json`)**:
  - Define rewrites rule `{"source": "/(.*)", "destination": "/"}` to prevent 404 errors on browser refresh for dynamic paths (`/courses/:slug`, `/courses/:slug/lessons/:lessonSlug`, `/my-learning`).
  - Set security headers (X-Content-Type-Options, X-Frame-Options).
- **Backend Configuration (`render.yaml` & `backend/render.yaml`)**:
  - Blueprint service named `vibelearn-backend`.
  - Build Command: `npm install`.
  - Start Command: `npm start`.
  - Health Check Path: `/api/health`.
  - Environment variables: `NODE_ENV=production`, `PORT=10000`, `DATABASE_URL`, `CLERK_SECRET_KEY`, `CLERK_PUBLISHABLE_KEY`, `FRONTEND_URL`.
- **Production Environment Documentation (`docs/deployment.md`)**:
  - Complete guide for setting up Supabase, Render, Vercel, and Clerk, linking environment variables and verifying deployment health.
- **Verification**:
  - Run `npm run lint` on both `backend/` and `frontend/`.
  - Run `npm run build` in `frontend/`.
