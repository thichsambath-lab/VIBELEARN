## 4. Decisions and Assumptions
- **Backend Authentication (`src/middlewares/auth.js`)**:
  - Install `@clerk/express` in `backend/`.
  - Mount Clerk middleware in `src/index.js` to parse tokens from incoming requests.
  - Implement `requireAuth` middleware for `/api/progress` routes. It validates Clerk session JWTs from `Authorization: Bearer <token>` and populates `req.auth = { userId: ... }`.
  - For developer testing when live Clerk credentials are placeholders (`sk_test_...`), provide graceful fallback if `req.query.userId` or header `x-user-id` is supplied, while enforcing JWT verification when tokens are present.
- **Frontend API Client (`frontend/src/services/api.js`)**:
  - Centralize all HTTP calls to the backend using native `fetch`.
  - Base URL defaults to `import.meta.env.VITE_API_URL || 'http://localhost:5000/api'`.
  - Endpoints:
    - `fetchCourses()` -> `GET /api/courses`
    - `fetchCourseBySlug(slug)` -> `GET /api/courses/:slug`
    - `fetchLessonBySlug(slug)` -> `GET /api/lessons/:slug`
    - `fetchUserProgress(token)` -> `GET /api/progress` (with `Authorization: Bearer <token>`)
    - `saveUserProgress(token, progressData)` -> `POST /api/progress` (with `Authorization: Bearer <token>`)
  - Resilient fallback: If the backend is loading or momentarily unreachable, seamlessly return cached mock data so the UI remains stable.
- **Frontend Custom Hook (`frontend/src/hooks/useProgress.js`)**:
  - Uses Clerk `useAuth()` to get the current learner's authentication token (`getToken()`) and user identity (`userId`).
  - Fetches and stores user progress records.
  - Provides `saveProgress(lessonId, { isCompleted, resumeTimestamp })`.
  - Provides `markAsCompleted(lessonId)`.
  - Provides helper `getLessonProgress(lessonId)` to check completion state and resume position.
- **Page Data Hookup**:
  - **Catalog (`Catalog.jsx`)**: Replaces `MOCK_COURSES` with `fetchCourses()` from `api.js`. Includes loading state and graceful fallback.
  - **Course Detail (`CourseDetail.jsx`)**: Replaces mock course with `fetchCourseBySlug(slug)`. Renders real modules and lessons from the database.
  - **Lesson Page (`Lesson.jsx`)**: Replaces mock lesson with `fetchLessonBySlug(lessonSlug)`.
    - Resumes YouTube playback from saved `resumeTimestamp` (via `&start=${resumeTimestamp}`).
    - Wires "Mark as Complete" button to `saveProgress` API.
    - Saves video progress periodically / on navigation.
  - **My Learning (`MyLearning.jsx`)**: Fetches user progress and calculates accurate course completion percentages.

- Client passes `Authorization: Bearer <token>` fetched via Clerk's `getToken()`.
