## 4. Decisions and Assumptions
- **Design Tokens**:
  - Primary Emerald palette: `500: #10B981`, `400: #34D399`, `300: #6EE7B7`, `200: #A7F3D0`, `100: #D1FAE5`.
  - Neutral Slate palette: `900: #0F172A`, `700: #334155`, `500: #64748B`, `300: #CBD5E1`, `200: #E2E8F0`, `100: #F1F5F9`, `50: #FAFAFC`.
  - Fonts: Google Fonts `Playfair Display` (serif, display headings) and `Inter` (sans, UI/body).
- **Mock Data Layer**:
  - Create centralized mock data in `frontend/src/services/mockData.js` matching the real database schema (`courses`, `modules`, `lessons`, `progress`) so switching to real API in Phase 4 is seamless.
- **YouTube Embed Player**:
  - Embedded `<iframe>` player referencing YouTube video IDs with privacy-enhanced mode (`youtube-nocookie.com`), with start-time support via URL parameter (`&start=sec`).
- **Route Guarding**:
  - Public routes: `/` (Home/Catalog), `/courses`, `/courses/:slug`, `/courses/:slug/lessons/:lessonSlug`.
  - Protected route: `/my-learning` protected by Clerk `<SignedIn>` and `<SignedOut>` with `<RedirectToSignIn />` or fallback banner.
- **Header & Navigation**:
  - Top navigation bar featuring Vibe Learn logo, "Courses" and "My Learning" links, notification bell, and Clerk `<UserButton />` / `<SignInButton>`.

## 7. Security Considerations
- Use `VITE_CLERK_PUBLISHABLE_KEY` from environment variables; do NOT hardcode keys.
- Never include database credentials or server secrets on the frontend.
- Secure YouTube iframe embeds with `allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"` and sandbox safe flags.

## 10. Manual Test Steps

2. Navigate to `http://localhost:5173` - Verify hero, popular courses, and feature cards match `home-page.png`.
3. Click on a course card - Navigate to `/courses/nextjs-for-production`. Verify course details, modules accordion, and progress bar match `detail-page.png`.
4. Click "Continue Learning" or a lesson item - Navigate to `/courses/nextjs-for-production/lessons/data-fetching-caching`. Verify sidebar curriculum, YouTube player embed, content tabs, and navigation match `learning-page.png`.
5. Click "My Learning" in the top navbar - Verify dashboard renders with course cards and progress bars.
6. Test mobile view (viewport width < 768px) and verify sidebar collapses and elements stack cleanly.
