## 4. Decisions and Assumptions
- **Database Driver**: Use `postgres` (postgres.js) with `drizzle-orm/postgres-js` for robust, connection-pooled PostgreSQL queries.
- **Database Schema (`src/db/schema.js`)**:
  - `users`: `id` (text, PK, Clerk user ID), `email` (text), `created_at` (timestamp, defaultNow).
  - `courses`: `id` (uuid, PK, defaultRandom), `title` (text, notNull), `slug` (text, notNull, unique), `summary` (text), `cover_image_url` (text), `level` (text), `created_at` (timestamp, defaultNow).
  - `modules`: `id` (uuid, PK, defaultRandom), `course_id` (uuid, FK -> courses.id, onDelete: cascade), `title` (text, notNull), `summary` (text), `position` (integer, notNull, default 1).
  - `lessons`: `id` (uuid, PK, defaultRandom), `module_id` (uuid, FK -> modules.id, onDelete: cascade), `title` (text, notNull), `slug` (text, notNull, unique), `youtube_video_id` (text), `duration` (integer), `notes` (text), `position` (integer, notNull, default 1).
  - `progress`: `id` (uuid, PK, defaultRandom), `user_id` (text, notNull), `lesson_id` (uuid, FK -> lessons.id, onDelete: cascade), `is_completed` (boolean, default false), `resume_timestamp` (integer, default 0), `updated_at` (timestamp, defaultNow).
- **Seeding Script (`src/db/seed.js`)**:
  - Parses `docs/seed.ndjson` and `docs/videos.json`.
  - Normalizes courses, nested modules, and lessons.
  - Links YouTube video IDs and duration from `videos.json` / `seed.ndjson`.
  - Upserts records idempotently without duplicate key errors.
- **Layered Backend Architecture**:
  - **Repositories**: `course.repository.js`, `lesson.repository.js`, `progress.repository.js` handling pure Drizzle queries.
  - **Services**: `course.service.js`, `lesson.service.js`, `progress.service.js` encapsulating business logic and data transformations.
  - **Controllers**: `course.controller.js`, `lesson.controller.js`, `progress.controller.js` handling HTTP requests and responses.
  - **Routes**: `course.routes.js`, `lesson.routes.js`, `progress.routes.js` registered in `src/index.js` under `/api`.
- **API Endpoints**:
  - `GET /api/courses` - List all courses with module/lesson summaries.
  - `GET /api/courses/:slug` - Get course detail by slug with all nested modules and lessons.
  - `GET /api/lessons/:slug` - Get lesson detail by slug including module and course context.
  - `GET /api/progress` - Get learner progress for a user (query param `userId` or mock user).
  - `POST /api/progress` - Save / update learner progress (`userId`, `lessonId`, `isCompleted`, `resumeTimestamp`).
  - Fallback / Mock Mode: If database credentials are not yet supplied or database connection fails, repository layers will gracefully serve data or log descriptive configuration notices.
